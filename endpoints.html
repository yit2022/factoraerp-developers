Endpoints

All endpoints are GET, return JSON with Cache-Control: no-store, and return the newest records first. List endpoints accept limit and before (see Pagination). A field is omitted when the record has no value for it.

GET /api/v1/me

Checks a key and shows what it can do.

{"ok":true,"organizationId":"<factory id>","scopes":["read:customers"]}

GET /api/v1/customers

Scope read:customers.

FieldNotes
idFactoraERP record id
customerCode
name
email
phone
taxPinKRA PIN
status
_creationTimeCreation time, ms since epoch. Used for paging.
