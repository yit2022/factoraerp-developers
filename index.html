Getting started

The FactoraERP API gives your systems read-only access to one factory's customers, inventory items and sales invoices, plus signed webhooks for key events.

API v1 is read-only. Webhook delivery is currently in dry-run mode: events are signed and logged but not sent.

Quick start

  1. A factory admin (Admin, CEO/Director or General Manager role) opens System Settings → API access in FactoraERP.
  2. They create a key, choose its scopes and expiry, and copy it. The key starts with fxk_ and is shown only once.
  3. Call the API with the key in a header:
curl -H "Authorization: Bearer $FACTORA_API_KEY" https://brazen-raven-302.convex.site/api/v1/me
{"ok":true,"organizationId":"<factory id>","scopes":["read:customers","read:sales"]}

What's available

EndpointScope
GET /api/v1/meany valid key
GET /api/v1/customersread:customers
GET /api/v1/inventory-itemsread:inventory
GET /api/v1/sales-invoicesread:sales

The API is designed for server-to-server use. It sends no CORS headers, so browsers will block calls from web pages. Keep keys on your server.
