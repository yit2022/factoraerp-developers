Errors

Errors return a JSON body of {"ok": false, "error": "<message>"}.

StatuserrorCause
401Missing API keyNo key, or the value doesn't start with fxk_.
401Send the key in the Authorization (Bearer) or X-API-Key headerThe request had an api_key query parameter.
401Invalid, expired or revoked API keyUnknown, expired or revoked key.
403This key lacks the read:… scopeThe key lacks the scope for this endpoint.
400limit and before must be numbersBad paging parameters.
404Not foundUnknown resource.

Requests to paths outside the four documented endpoints may get a plain-text 404 from the platform rather than JSON. Unexpected server errors return 5xx; retry with backoff.
